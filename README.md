## Install

Requires OpenJade 0.5.1 (English audio) and PoP Mod Manager 2.1.2.

1. In Mod Manager, select **OpenJade → The Two Thrones** and import the `.jtmod`.
2. Disable any older WW Prince / model / sword / voice mod.
3. Enable this one, click **Apply**, and launch the game.

**Uninstall:** close the game, then **Restore original** in Mod Manager.

Not for the Classic/Steam engine. Back up your saves.
Upgrading, or WW voice still playing after uninstall? See [Installation](docs/INSTALLATION.md).
