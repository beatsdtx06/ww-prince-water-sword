WW PRINCE - MODEL, WATER SWORD & VOICE 0.6.0
OPENJADE ONLY - NOT THE ORIGINAL STEAM ENGINE

Requires an existing OpenJade 0.5.1 TTT installation with supported English audio, and PoP Mod Manager 2.1.2 with native JTMod v9 support.

INSTALL
1. Extract this ZIP.
2. Import WW-Prince-Model-Sword-Voice-0.6.0.jtmod into Mod Manager for OpenJade -> The Two Thrones.
3. Disable older WW Prince/model/sword/voice packages. Enable this one and Apply.
4. Launch the game.

No CMD, PowerShell, API key, AI runtime, executable patch, or extra setup step.
Back up saves and retain Mod Manager backups. Do not stack overlapping model/audio mods.
To uninstall, close the game and use Mod Manager Restore original.
